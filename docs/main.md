# AutoDub API Reference

This document describes the main inference and media-processing functions used by the AutoDub pipelines. Unless stated otherwise, paths are strings, CSV files use UTF-8 encoding with a semicolon (`;`) delimiter, and output directories are created automatically.

## Inference methods

### `inference_asr`

```python
from source.inference import inference_asr

output_file_path = inference_asr(cfg)
```

Transcribes speech inside time boundaries generated by the VAD stage. The function supports either DeepSpeech2 or Whisper and processes each detected speech segment separately.

Defined in `source/inference/asr/inference_asr.py`.

#### Configuration

- `type` (`str`): ASR backend. Supported values are `"ds2"` and `"whisper"`.
- `filepath` (`str`): path to the source speech WAV file.
- `boundaries` (`str`): path to a SpeechBrain boundaries file. Lines marked `SPEECH` are processed.
- `output_dir` (`str`): directory for processed audio and transcription results.
- `sr` (`int`): target sample rate. Audio is resampled and converted to mono when required.
- `model`: for Whisper, a model name such as `"small.en"`; for DeepSpeech2, a model configuration path.
- `checkpoint_path` (`str`): Whisper cache directory or DeepSpeech2 checkpoint path.
- `n_gpu` (`int`, DeepSpeech2 only): requested number of GPUs.

#### Processing

1. Loads and normalizes the audio with `load_n_process_audio`.
2. Reads `(start, end)` pairs from the VAD boundaries file.
3. Cuts each region from the waveform.
4. Runs the selected ASR backend.
5. Writes a CSV containing `id`, `start`, `end`, and `text`.

DeepSpeech2 converts each segment to a log Mel spectrogram and decodes CTC probabilities with the project text encoder and language model. Whisper pads or trims each segment, creates a log Mel spectrogram, and decodes it as English speech.

#### Returns

`str`: path to `<output_dir>/<audio_name>/<audio_name>_asr.csv`.

### `inference_asr_wtime`

```python
from source.inference import inference_asr_wtime

processed_audio_path, output_file_path = inference_asr_wtime(cfg)
```

Runs Whisper on the complete speech recording and uses Whisper segment timestamps instead of an external VAD boundaries file.

Defined in `source/inference/asr/inference_asr_wtime.py`.

#### Configuration

- `model` (`str`): Whisper model name. Supported values include `tiny`, `base`, `small`, `medium`, `large`, versioned large models, and their available English-only variants.
- `filepath` (`str`): path to the input speech WAV file.
- `output_dir` (`str`): output directory.
- `sr` (`int`): target sample rate, normally `16000`.
- `checkpoint_path` (`str`): directory used by Whisper to cache model files.

#### Processing

The function selects CUDA when available, loads Whisper, normalizes the input audio, and calls `model.transcribe(..., word_timestamps=True)`. Utterance-level segment data is saved with the columns `id`, `start`, `end`, and `text`.

#### Returns

`tuple[str, str]`:

1. path to the normalized audio file;
2. path to the generated ASR CSV file.

---

### `inference_bsrnn`

```python
from source.inference import inference_bsrnn

speech_path, background_path = inference_bsrnn(cfg)
```

Separates a mixed soundtrack into speech and background using the BandIt/Band-Split RNN model.

Defined in `source/inference/bsrnn/inference_bsrnn.py`.

#### Configuration

- `model` (`str`): path to the Hydra/OmegaConf model architecture YAML.
- `checkpoint_path` (`str`): path to the trained checkpoint. The checkpoint must contain a `state_dict` key.
- `filepath` (`str`): path to the input audio file.
- `output_dir` (`str`): output directory.
- `sr` (`int`): target sample rate, normally `44100`.
- `max_len` (`float`): maximum duration in seconds processed as one block.
- `use_fader` (`bool`): enables overlap-add inference for long recordings.
- `window_type` (`str`): overlap-add window type.
- `chunk_size_second` (`float`): overlap-add chunk duration.
- `hop_size_second` (`float`): overlap-add hop duration.
- `batch_size` (`int`): overlap-add inference batch size.

#### Processing

The model architecture is instantiated from YAML and loaded on CUDA when available. Long recordings are processed either in fixed-size segments or through `OverlapAddFader`. The model's `speech` output becomes the dialogue track, while the background track is calculated as `mixture - speech`.

#### Returns

`list[str]`:

1. path to `<audio_name>_speech.wav`;
2. path to `<audio_name>_background.wav`.

Both files are stored under `<output_dir>/<audio_name>/`.

---

### `inference_cascaded`

```python
from source.inference.cascaded.inference_cascaded import inference_cascaded

vocal, background, sample_rate = inference_cascaded(cfg)
```

Separates vocals and background with CascadedNet using spectrogram-domain inference.

Defined in `source/inference/cascaded/inference_cascaded.py`.

#### Configuration

- `checkpoint_path` (`str`): path to the CascadedNet state dictionary.
- `filepath` (`str`): input audio path.
- `output_dir` (`str`): output directory.
- `n_fft` (`int`): FFT size used for the spectrogram.
- `hop_length` (`int`): STFT hop length.
- `batchsize` (`int`): separator batch size.
- `cropsize` (`int`): spectrogram crop size.
- `postprocess` (`bool`): enables separator post-processing.
- `save` (`bool`): selects path output or in-memory tensor output.

#### Processing

Audio is loaded at 44.1 kHz. Mono input is duplicated to stereo, transformed into a spectrogram, separated by CascadedNet, and transformed back into waveforms.

#### Returns

When `save=True`:

```python
[vocal_save_path, background_save_path, 44100]
```

When `save=False`:

```python
(vocal_tensor, background_tensor, 44100)
```

### `inference_vad`

```python
from source.inference import inference_vad

processed_audio_path, boundaries_path = inference_vad(cfg)
```

Detects speech regions with the SpeechBrain `vad-crdnn-libriparty` model.

Defined in `source/inference/vad/inference_vad.py`.

#### Configuration

- `filepath` (`str`): input audio path.
- `output_dir` (`str`): output directory.
- `sr` (`int`): target sample rate.
- `checkpoint_path` (`str`): SpeechBrain model cache directory.
- `activation_th` (`float`): energy VAD activation threshold.
- `deactivation_th` (`float`): energy VAD deactivation threshold.
- `close_th` (`float`): maximum gap in seconds for merging neighboring speech regions.
- `len_th` (`float`): minimum retained segment duration in seconds.

#### Processing

The method normalizes audio, obtains neural VAD predictions, refines them with energy VAD, merges close regions, removes short regions, and saves the resulting boundaries.

#### Returns

`list[str]`:

1. path to the normalized audio file;
2. path to `<audio_name>_boundaries.txt`.

### `label_speakers`

```python
from source.inference import label_speakers

labeled_csv_path = label_speakers(
    audio_filepath,
    csv_filepath,
    output_dir,
    cluster_type,
    cluster_cfg,
)
```

Assigns a speaker label to every timestamped speech segment.

Defined in `source/inference/diarize/inference_diarization.py`.

#### Parameters

- `audio_filepath` (`str`): path to the speech-only audio.
- `csv_filepath` (`str`): semicolon-separated CSV containing `start` and `end` columns.
- `output_dir` (`str`): output directory.
- `cluster_type` (`str`): configured clustering backend.
- `cluster_cfg` (`dict`): keyword arguments passed to the selected backend.

#### Processing

Each timestamped audio segment is encoded with SpeechBrain's `spkrec-ecapa-voxceleb` model. The resulting speaker embeddings are grouped, and the generated label for each segment is added to the source DataFrame.

#### Returns

`str`: path to `<output_dir>/<csv_name>/<csv_name>_labeled.csv`. The output contains all original columns plus `label`.

### `translate_file`

```python
from source.inference import translate_file

translated_csv_path = translate_file(cfg)
```

Translates recognized English text into Russian.

Defined in `source/inference/translate/inference_translate.py`.

#### Configuration

- `filepath` (`str`): input transcription CSV.
- `output_dir` (`str`): output directory.
- `use` (`str`): translation backend, either `"opusmt"` or `"google"`.
- `checkpoint_path` (`str`): Hugging Face cache directory used by OPUS-MT.

#### Input columns

- OPUS-MT reads source text from `text`.
- Google Translate reads source text from `transcription`.

#### Processing

The OPUS-MT backend loads `Helsinki-NLP/opus-mt-en-ru`, tokenizes each input string, generates a translation with beam search, and decodes it. The Google backend sends each string to `googletrans.Translator` with Russian as the destination language.

#### Returns

`str`: path to `<output_dir>/<csv_name>/<csv_name>_tr.csv`. The output contains the original columns plus `translation`.

---

### `tts`

```python
from source.inference import tts

tts_csv_path = tts(
    csv_filepath,
    output_dir,
    filename,
    target_sr,
    checkpoint_path,
)
```

Generates Russian speech with Coqui XTTS using both an utterance reference and a combined speaker reference.

Defined in `source/inference/tts/inference_tts.py`.

#### Parameters

- `csv_filepath` (`str`): input CSV containing `translation`, `path`, and `path_to_common`.
- `output_dir` (`str`): output directory.
- `filename` (`str`): directory name used for generated artifacts.
- `target_sr` (`int`): output sample rate.
- `checkpoint_path` (`str`): XTTS checkpoint directory containing `config.json` and model weights.

#### Processing

For each row, XTTS extracts conditioning latents and speaker embeddings from:

1. the current source utterance in `path`;
2. concatenated reference speech for the same speaker in `path_to_common`.

The two conditioning representations are averaged. XTTS then generates Russian audio at 24 kHz, which is resampled to `target_sr` and stored in `<output_dir>/<filename>/segments/`.

#### Returns

`str`: path to a new CSV containing all input columns plus `tts_path`.

---

### `lazy_tts`

```python

    checkpoint_path,
```

Generates Russian speech with XTTS using one reference utterance per segment.

Defined in `source/inference/tts/inference_tts_lazy.py`.

#### Parameters

- `csv_filepath` (`str`): CSV containing `translation` and `path`.
- `output_dir` (`str`): output directory.
- `filename` (`str`): output group name.

- `checkpoint_path` (`str`): XTTS checkpoint directory.

#### Returns

`str`: path to a CSV containing the added `tts_path` column.

## Audio and media utilities

### `load_n_process_audio`

```python
from source.utils.process_audio import load_n_process_audio

audio, processed_path = load_n_process_audio(filepath, output_dir, sr)
```

Loads audio with Torchaudio, resamples it to `sr`, and averages multiple channels into one mono channel. If the waveform changes, the processed WAV is saved under `output_dir`; otherwise, the original path is returned.

#### Returns

`list`: the normalized `torch.Tensor` and its file path.

---

### `separate_audio_n_video`

```python
from source.utils.process_audio import separate_audio_n_video

audio_path, video_path = separate_audio_n_video(filepath, output_dir)
```

Uses MoviePy to extract a WAV soundtrack and create a video-only copy of an input video.

#### Returns

`list[str]`: extracted audio path and silent video path.

---

### `cut_n_save`

```python
from source.utils.process_audio import cut_n_save

audio_path, csv_with_paths = cut_n_save(filepath, output_dir, csv_filepath)
```

Cuts one WAV file per CSV row using the `start` and `end` timestamps. Segment paths are written to a new `path` column.

#### Returns

`tuple[str, str]`: the source audio path and the generated CSV path.

---

### `cut_n_save_by_label`

```python
from source.utils.process_audio import cut_n_save_by_label

audio_path, csv_with_paths = cut_n_save_by_label(
    filepath,
    output_dir,
    csv_filepath,
    save_segments=True,
    save_common=True,
)
```

Cuts timestamped utterances and organizes them into `speaker_<label>` directories. It can also concatenate all utterances assigned to a speaker into a shared reference WAV.

#### Input columns

The CSV must contain `id`, `start`, `end`, and `label`.

#### Output columns

- `path`: individual utterance WAV.
- `path_to_common`: concatenated reference WAV for the corresponding speaker.

#### Returns

`tuple[str, str]`: the source audio path and generated CSV path.

---

### `align_audio_length`

```python
from source.utils.process_audio import align_audio_length

aligned_csv_path = align_audio_length(csv_filepath, output_dir, filename)
```

Adjusts every synthesized segment to the duration defined by `end - start`. The input CSV must contain `start`, `end`, and `tts_path`. Aligned files are stored in `<output_dir>/<filename>/segments/`, and their paths are written to `aligned_tts`.

#### Returns

`str`: path to the CSV containing the added `aligned_tts` column.

---

### `concat_segments`

```python
from source.utils.process_audio import concat_segments

final_audio_path, final_video_path = concat_segments(
    speech_path,
    background_path,
    csv_filepath,
    filename,
    output_dir,
    join_video=False,
    video_path="",
)
```

Builds the final dubbed soundtrack and optionally attaches it to a video.

#### Parameters

- `speech_path` (`str`): speech stem that will receive generated segments.
- `background_path` (`str`): background stem mixed with the updated speech track.
- `csv_filepath` (`str`): CSV containing `start`, `end`, and `aligned_tts`.
- `filename` (`str`): output group and file-name prefix.
- `output_dir` (`str`): final output directory.
- `join_video` (`bool`): attaches final audio to `video_path` when enabled.
- `video_path` (`str`): path to the silent or original video stream.

#### Processing

Each aligned TTS segment is cropped or zero-padded to the exact target sample range and inserted into the speech stem. The updated speech is added to the background. If requested, MoviePy attaches the resulting WAV to the video.

#### Returns

`list[str]`:

1. path to `<filename>_final_audio.wav`;
2. path to the final video, or an empty string when `join_video=False`.

## Pipeline entry points

### `dub_baseline.py`

Runs the VAD-based approach:

```text
media preprocessing
→ BSRNN separation
→ SpeechBrain VAD
→ segment-based ASR
→ translation
→ per-segment XTTS
→ alignment
→ final mix
```

It uses `source/configs/dub.yaml`.

### `dub.py`

Runs the diarization-aware approach:

```text
media preprocessing
→ BSRNN separation
→ timestamped Whisper ASR
→ speaker labeling
→ translation
→ speaker-aware XTTS
→ alignment
→ final mix
```

It uses `source/configs/dub_v2.yaml`.
